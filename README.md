# Hand Proximity Detector

This Python project uses OpenCV and MediaPipe to detect hands and estimate whether a hand is near or far from the webcam, based on the Z-axis depth data.

## 🔧 Features
- Real-time hand detection using webcam.
- Distance estimation using index finger tip depth.
- Visual hand landmark drawing on screen.

## 🧪 Requirements
- Python
- OpenCV
- MediaPipe

Install dependencies with:
```bash
pip install -r requirements.txt
